  1. 01

    FamilyCare ↗

    Aplicação web para organizar informações de saúde da família: familiares, medicamentos, alergias e comorbidades, com busca rápida e modo de emergência.

    • TypeScript
    • React
    • Next.js
    • Tailwind
    Case study completo

    Problema

    Nasceu de uma necessidade real: numa emergência médica na família (AVC do meu pai), não havia acesso rápido a informações críticas de saúde — medicamentos em uso, alergias, tipo sanguíneo. Apps genéricos de anotação não são pensados para esse cenário de urgência, onde cada segundo importa.

    Decisão técnica

    Construí com Next.js + React + TypeScript e um hook centralizado (use-family-store) para gerenciar estado e persistência local. Priorizei acessibilidade real, não só visual: gerenciamento de foco em modais, navegação por teclado, fechamento por Escape — detalhes que fazem diferença numa situação de estresse. Também escrevi testes automatizados com Vitest e Testing Library cobrindo os fluxos mais sensíveis (cadastro, modo emergência, troca de familiar), não só para garantir qualidade, mas para comprovar que sei testar componentes React de verdade, além do básico.

    Resultado

    Um "modo de emergência" que reduz a informação ao essencial em segundos, cadastro completo de familiares/medicamentos/alergias, e uma suíte de testes cobrindo os fluxos críticos da aplicação. É hoje o projeto que melhor representa minha maturidade técnica e minha capacidade de transformar uma dor real em produto.

  2. 02

    Vieste Concetto ↗

    Reformulação do site institucional e e-commerce de uma marca brasileira de moda, com experiência editorial, catálogo, busca, favoritos e sacola de compras.

    • TypeScript
    • React
    • Next.js
    • Tailwind
    Case study completo

    Problema

    A loja virtual da Vieste Concetto (marca real de moda contemporânea) tinha uma experiência digital que não refletia a identidade editorial da marca — navegação genérica e hierarquia visual fraca entre campanha, produto e conteúdo, o que prejudicava a percepção de valor da marca online.

    Decisão técnica

    Escolhi Next.js 16 (App Router) + React 19 pelo SSR e otimização nativa de imagens — essencial num e-commerce de moda com fotos pesadas. TypeScript para tipar catálogo, carrinho e favoritos com segurança. Tailwind CSS 4 para reconstruir rapidamente o design system da marca (paleta oficial, tipografia, vetorização dos logotipos). Mantive a persistência de sacola e favoritos local nesta fase, isolando a camada de apresentação da futura integração com backend e checkout — uma decisão consciente para entregar valor rápido sem acoplar a UI a uma API que ainda não existe.

    Resultado

    Reformulação funcional completa: vitrine, catálogo, busca, favoritos, sacola e cadastro, com fidelidade total ao manual de marca e performance otimizada. O comparativo antes/depois no repositório mostra o salto de qualidade visual e de experiência entre o site publicado e a reformulação.

  3. 03

    Scherr Química ↗

    Site institucional responsivo para uma empresa de tratamento de água industrial. Primeiro projeto freelancer, entregue com foco em performance e SEO.

    • HTML
    • CSS
    • JavaScript
    • Tailwind
    Case study completo

    Problema

    A Scherr Química (empresa de tratamento de água industrial onde eu já havia trabalhado como Gerente de Produção) não tinha presença digital própria — dependia de contato direto e boca a boca para apresentar seus serviços a novos clientes B2B. Faltava um site institucional que transmitisse credibilidade técnica logo no primeiro contato comercial.

    Decisão técnica

    Como primeiro projeto freelancer, optei por HTML5 semântico, CSS3 (Flexbox/Grid) e JavaScript puro — sem framework, para entregar rápido e com performance máxima, já que um site institucional não precisa da complexidade de uma SPA. Priorizei estrutura semântica e boas práticas de SEO on-page (hierarquia de headings, meta tags, imagens otimizadas) para melhorar o posicionamento orgânico da empresa, e validei responsividade em múltiplos dispositivos, já que grande parte do público B2B faz o primeiro contato pelo celular.

    Resultado

    Site institucional entregue dentro do prazo, com fidelidade total ao design solicitado pelo cliente. Foi meu primeiro projeto freelancer pago — e um marco de confiança particular, já que o cliente era uma empresa onde eu tinha atuado profissionalmente antes, o que reforça a credibilidade da entrega.

  4. 04

    Austen Cervejaria ↗

    Redesign completo do site institucional de uma cervejaria artesanal de Vespasiano (MG): experiência narrativa por "capítulos", animações coordenadas de scroll e layout totalmente responsivo.

    • React
    • Vite
    • Tailwind
    • GSAP
    Case study completo

    Problema

    O site atual da Austen Cervejaria (cervejaria real de Vespasiano, MG) é antigo, quebra em dispositivos móveis e não reflete a qualidade do produto. Como a maior parte do público chega pelo celular, a primeira impressão da marca online fica bem abaixo do que ela entrega na garrafa.

    Decisão técnica

    Montei um protótipo como proposta fria, não solicitada, para mostrar na prática o que uma modernização traria. Escolhi React 19 + Vite pela velocidade de build e DX, Tailwind CSS para reconstruir o design system da marca, e uma stack de animação (GSAP + ScrollTrigger + Lenis + Split Type) que reproduz o acabamento de sites premium feitos em Framer/Webflow. O conteúdo das cervejas ficou centralizado num único arquivo de dados (beers.js), separado dos componentes, para facilitar manutenção.

    Resultado

    Uma experiência editorial em que cada rótulo é um "capítulo", com scroll fluido, transições refinadas e responsividade real corrigindo as falhas do site original. O comparativo antes/depois mostra o salto de qualidade visual e de experiência.
