Sobre Mim

Desenvolvedor front-end com foco em React e JavaScript (ES6+), com dois anos de experiência prática em projetos freelancer. Especializado em transformar designs em interfaces funcionais, mantendo alta fidelidade visual (Pixel Perfect), performance e organização de código. Possuo domínio na construção de layouts responsivos com HTML5 semântico e CSS3 (Flexbox e Grid), além de experiência no desenvolvimento de componentes reutilizáveis, consumo de APIs REST e gerenciamento de estado em aplicações React. Mais do que implementar interfaces, busco entregar soluções que funcionam na prática: rápidas, consistentes e com boa experiência para o usuário. Atualmente, procuro integrar um time de desenvolvimento para contribuir em produtos escaláveis, colaborar em equipe e evoluir continuamente como desenvolvedor.
💻 Tecnologias: HTML | CSS | JavaScript | React 🚀 Atualmente: Freelancer 🎯 Objetivo: Desenvolvedor Front-end
